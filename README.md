# TalkMe: Anonymous Connections

Создай приложение анонимный чат название TalkMe с выбором пола возраста и общение чат или голос всё работает на сервере 

Функции 

Можно увидеть сколько пользователей сейчас онлайн 

В настройках можно изменить язык 

В настройках можно изменить цвет кнопки: белый , розовый и голубой 

Все кнопки без углов анимированые
